艦のデータ（端末間の同期・バックアップ）

自作の艦すべて（3Dモデル込み）を1つのファイルにします。別の端末でこの画面から読み込むと、同じ艦が使えます（同じ艦は更新日時の新しい方を残します）。iCloud Drive などで受け渡しできます。

GitHubで自動同期

設定のしかた
  1. GitHubで、艦のデータ専用の非公開（Private）リポジトリを作ります（例: space-ship-data。中身は空のままで大丈夫です）。
  2. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。 「Repository access」は Only select repositories で、1.のリポジトリだけを選びます。 「Permissions」の Repository permissions で Contents を Read and write にします。有効期限も選べます。
  3. 作成されたトークン（github_pat_ で始まる文字列）を、同期したい端末ごとにこの画面に貼り付け、リポジトリ名（例: ユーザー名/space-ship-data）を入れて「保存して接続を確認」を押します。

トークンはこの端末のブラウザの中にだけ保存され、GitHub以外には送られません。艦のデータは非公開のリポジトリに入るので公開されません。 なお、同じ github.io のアドレスで動いているほかのページからもブラウザに保存したトークンは読めるため、トークンの権限は必ず上のように「このリポジトリの中身の読み書きだけ」にしてください。

同期は「更新日時の新しい方が勝つ」方式です。2台で同じ艦を同時に編集した場合は、後で保存した方が残ります。船体モデルは1つ70MBくらいまで同期できます。
