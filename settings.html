Googleアカウントで自動同期

同じGoogleアカウントでログインした端末どうしで、自作の艦（3Dモデル込み）が自動で同期されます。ログインは端末ごとに1回だけです。

最初の準備（サイトの持ち主が1回だけ・無料）

このサイトには Firebase の設定が書き込まれています（firebase-config.js）。各端末では「Googleでログイン」を押すだけで使えます。

このゲームにはサーバーが無いので、Google の無料サービス「Firebase」に艦のデータの置き場所を1つ作ります。パソコンかiPadのブラウザで、次のとおりに進めてください。

  1. Firebase コンソールをGoogleアカウントで開き、「プロジェクトを作成」（名前は自由。例: space-ships。Google アナリティクスはオフで大丈夫です）。
  2. プロジェクトの画面で「ウェブ」（</> のマーク）を押してアプリを追加します（ニックネームは自由。Firebase Hosting は不要）。表示される firebaseConfig の内容をコピーします。
  3. 左のメニューの「構築」→「Authentication」→「始める」→「ログイン方法」で「Google」を選び、有効にして保存します。
  4. Authentication の「設定」→「承認済みドメイン」→「ドメインを追加」で を追加します。
  5. 「構築」→「Firestore Database」→「データベースを作成」。場所は asia-northeast1（東京） など近いところ、「本番環境モード」で作成します。
  6. Firestore の「ルール」タブの中身を下のルールに置き換えて「公開」します（自分のデータは自分だけが読み書きできるようになります）。
  7. 2.でコピーした firebaseConfig を下の欄に貼り付けて「設定を保存」し、「Googleでログイン」を押します。

          

          
          

            
            
          

          
貼り付けた設定はこの端末にだけ保存されます。リポジトリの firebase-config.js に書いておくと、どの端末でも貼り付けずに「Googleでログイン」だけで使えます。この設定は秘密の情報ではありません（データは上のルールで本人だけに守られます）。

        

        
無料プラン（Spark）のままで使えます（保存できるのは合計1GBまで。船体モデルは1つ200MBまで）。同期は「更新日時の新しい方が勝つ」方式です。2台で同じ艦を同時に編集した場合は、後で保存した方が残ります。

      


      

      
ファイルで受け渡し（設定不要）

      

        
        
        
      

      
自作の艦すべて（3Dモデル込み）を1つのファイルにします。別の端末でこの画面から読み込むと、同じ艦が使えます（同じ艦は更新日時の新しい方を残します）。iCloud Drive などで受け渡しできます。

      


      

        GitHubで同期（別の方法）
        
        
        
        

          
          
          
        

        

        
    
          
  1. GitHubで、艦のデータ専用の非公開（Private）リポジトリを作ります（例: space-ship-data。中身は空のままで大丈夫です）。
    2. 
          
  2. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
            「Repository access」は Only select repositories で、1.のリポジトリだけを選びます。
            「Permissions」の Repository permissions で Contents を Read and write にします。有効期限も選べます。
    3. 
          
  3. 作成されたトークン（github_pat_ で始まる文字列）を、同期したい端末ごとにこの画面に貼り付け、リポジトリ名（例: ユーザー名/space-ship-data）を入れて「保存して接続を確認」を押します。
    4. 
        

        
トークンはこの端末のブラウザの中にだけ保存され、GitHub以外には送られません。艦のデータは非公開のリポジトリに入るので公開されません。
          なお、同じ github.io のアドレスで動いているほかのページからもブラウザに保存したトークンは読めるため、トークンの権限は必ず上のように「このリポジトリの中身の読み書きだけ」にしてください。

        
同期は「更新日時の新しい方が勝つ」方式です。船体モデルは1つ70MBくらいまで同期できます。Googleアカウントでの同期と両方を設定した場合は、両方と同期します。
